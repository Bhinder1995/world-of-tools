How It Works

A JWT consists of three Base64URL-encoded parts separated by dots: header.payload.signature. The tool:

1. Splits the token on . characters.
2. Base64URL-decodes the header and payload sections.
3. Parses each as JSON and displays them formatted.
4. Reads exp (expiry), iat (issued at), and nbf (not before) Unix timestamps and converts them to human-readable dates.

The signature is not verified (that requires the secret key) — this tool is for inspection only.

Frequently Asked Questions (FAQ)

Can this verify a JWT signature?

No — signature verification requires the secret key or public certificate and must be done server-side. This tool is for payload inspection only.

Is it safe to paste a production JWT here?

Since decoding is fully client-side, the risk is low compared to using an online service that sends data to a server. As a best practice, always rotate tokens after sharing them outside secure environments.

What is a JWT used for?

JWTs are used for stateless authentication — a server issues a signed token containing user claims, which the client sends with each request. The server verifies the signature to authenticate without storing session state.

What does 'exp' mean in a JWT?

`exp` is the expiry timestamp (Unix time). The server should reject tokens with an expired `exp` value.

Can I use this to debug OAuth tokens?

Yes — OAuth access tokens are often JWTs. Paste the token here to inspect scopes, user ID, and expiry without needing the signing secret.

Frequently Asked Questions

What is a JWT?

A JSON Web Token is an encoded string used for authentication. It has three parts: header, payload, and signature.

Is it safe to decode online?

Yes — this tool is 100% client-side. Your token never leaves your browser.

Can I verify the JWT signature?

Signature verification requires the secret key. This tool decodes the data payload only.

What does exp mean in a JWT?

exp is the expiry timestamp (Unix time). The token is invalid after this time.

My JWT says it expired — why?

The current time is past the exp claim. You need a fresh token from your auth server.
