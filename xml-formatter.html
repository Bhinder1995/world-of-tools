Frequently Asked Questions

What is the difference between XML formatting and XML validation?

Formatting makes XML readable with indentation. Validation checks that XML is well-formed (properly nested tags, closed elements, correct attribute syntax).

Can this validate XML Schema (XSD)?

This tool validates well-formedness only. Full XSD schema validation requires a dedicated XML Schema validator.

Does it support SOAP and RSS XML?

Yes — any standard XML document including SOAP envelopes, RSS feeds, Atom feeds, XHTML, and configuration XML files.
