Frequently Asked Questions

What is an HTML email signature?

An HTML email signature is formatted code added at the bottom of your emails with your name, title, company, contact details and social links with styling.

How do I add this signature to Gmail?

Click Copy HTML, then in Gmail go to Settings → See all settings → General → Signature → Create new. Click the HTML source icon and paste.

How do I add this to Outlook?

Copy the HTML. In Outlook go to File → Options → Mail → Signatures → New. In the editor click HTML source view and paste the code.

Is this email signature generator free?

Yes, 100% free. No signup, no watermark. Generate and copy unlimited signatures.
