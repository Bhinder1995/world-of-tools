How It Works

The text compare tool uses a Longest Common Subsequence (LCS) algorithm — the same approach used in tools like Git diff:

1. Both texts are split into lines (or words, depending on mode).
2. The LCS algorithm finds the longest common sequence of lines between both texts.
3. Lines in Text B but not Text A are marked as added (green).
4. Lines in Text A but not Text B are marked as removed (red).
5. Identical lines are shown as unchanged.

Everything runs in JavaScript locally — no server involved.

Step-by-Step Guide:

  1. Paste Text A – Add your original or reference text in the left panel.
  2. Paste Text B – Add the modified or updated text in the right panel.
  3. Click Compare – See all differences highlighted instantly.
  4. Toggle View Mode – Switch between line-level and word-level comparison.

Frequently Asked Questions (FAQ)

How do I compare two texts online?

Paste your original text in the left box and the updated text in the right box, then click Compare. Differences are highlighted immediately.

Can this compare source code?

Yes — paste any programming language code (JavaScript, Python, CSS, HTML, SQL, etc.) and see exactly what changed between versions.

Is this good for proofreading?

Yes — compare a draft against a revised version to see every change made by an editor or collaborator.

Can I compare Word document content?

Yes — copy-paste content from Word documents into both panels. The tool compares plain text content.

Is my text stored or shared?

No. Comparison runs entirely in your browser. Nothing is stored, cached, or transmitted.

Does it show the number of differences?

Yes — a summary of total additions, deletions, and changed line count is shown above the comparison panels.

Can I use this for legal or contract comparison?

Yes — useful for comparing contract versions, policy revisions, terms and conditions changes, or any formal document edits.
