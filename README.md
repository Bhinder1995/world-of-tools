## Deployment Instructions

### Option 1: Static Hosting (Recommended)

**Deploy to Vercel, Netlify, or Cloudflare Pages:**

1. Upload all files to your repository
2. Connect your Git repository
3. Deploy with one click
4. Your site will be live at: `yoursite.vercel.app`

### Option 2: Traditional Hosting

1. Upload all files to your web hosting via FTP
2. Ensure all .html files are in the root directory
3. Set `index.html` as the default page
4. Your site is live!

### Option 3: GitHub Pages

1. Create a new repository
2. Upload all files
3. Go to Settings → Pages
4. Select main branch
5. Your site will be at: `username.github.io/repo-name`

## Customization Guide

### Change Colors

Edit the `:root` CSS variables in any file:

```css
:root {
    --primary: #2c5282;        /* Main blue color */
    --primary-dark: #1a365d;   /* Darker blue */
    --secondary: #48bb78;      /* Green accent */
    --background: #f7fafc;     /* Page background */
    --surface: #ffffff;        /* Card background */
}
```

### Add Your Logo

Replace the logo section in the header:

```html
<div class="logo-icon">WT</div>  <!-- Change WT to your initials -->
```

### Update Branding

1. Replace "WorldOfTools" with your brand name in all files
2. Update the tagline "Fast. Free. Simple." to your tagline
3. Customize footer text
