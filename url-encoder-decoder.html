Frequently Asked Questions (FAQ)

What is URL encoding?

URL encoding converts characters that are not allowed in URLs (like spaces, `&`, `=`, `#`) into a `%xx` format where `xx` is the character's hexadecimal ASCII value. Space becomes `%20`.

When do I need to URL-encode?

Anytime you pass data in a URL query string, form POST body, or API request parameter — special characters must be encoded to avoid breaking the URL structure.

What is the difference between `%20` and `+` in URLs?

Both represent a space. `%20` is standard percent-encoding (RFC 3986). `+` represents space in `application/x-www-form-urlencoded` format (HTML forms). Use `%20` for general URLs.
