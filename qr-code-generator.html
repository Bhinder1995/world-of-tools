How It Works

QR codes are generated using the QRCode.js library running locally in your browser. Your input data is encoded into a matrix of black and white squares following the ISO/IEC 18004 standard. Error correction data is added so the code remains scannable even if partially obscured. The final image is exported as a PNG using the Canvas API — no server contact required.

Frequently Asked Questions (FAQ)

How do I create a QR code for a website?

Select "URL" type, paste your website link, click Generate, and download your QR code as PNG.

Do QR codes expire?

Static QR codes (like those generated here) never expire — they simply encode data in a pattern that any QR scanner can read.

What error correction level should I use?

Level H (30% recovery) for printed materials that might get worn or dirty. Level L for digital-only use where maximum data density is needed.

Can I create a QR code for Wi-Fi?

Yes — select Wi-Fi type, enter your SSID and password, and generate a QR code guests can scan to connect automatically.

Is there a limit to how much data a QR code can hold?

QR codes can hold up to ~4,296 alphanumeric characters. For long URLs, use the [Link Shortener](#) first to keep your QR code less dense and more scannable.
