Introduction: The Eternal Language of Numbers

Long before the decimal (Hindu-Arabic) system we use today became the global standard, the Roman Empire developed its own numeric system based on letters of the alphabet. Even thousands of years later, Roman Numerals haven't disappeared. They signify tradition, prestige, and timelessness. The Seven Basic Symbols

The entire system is built on these seven characters:

  • I: 1
  • V: 5
  • X: 10
  • L: 50
  • C: 100
  • D: 500
  • M: 1,000

The Rules of the Game: Additive vs. Subtractive

Unlike our decimal system, Roman Numerals don't use place value (a '1' in the tens spot). Instead, the value is determined by the order of the letters:

  • Additive Rule: If a smaller value follows a larger value, you add it. Example: `VI` (5 + 1) = 6.
  • Subtractive Rule: If a smaller value *precedes* a larger value, you subtract it. Example: `IV` (5 - 1) = 4. This rule is used to prevent four identical symbols in a row (so `IV` is used instead of `IIII`).
  • The Logic of Four: A symbol can never be repeated more than three times consecutively (so 40 is `XL`, not `XXXX`).
