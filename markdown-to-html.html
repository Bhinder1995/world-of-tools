Frequently Asked Questions (FAQ)

How do I convert Markdown to HTML?

Paste your Markdown text into the left panel. The tool instantly converts it to HTML and shows the rendered preview on the right. Copy the HTML source code to use in your project.

Can I use this for README files?

Yes — paste GitHub README.md content to preview it as HTML or convert it for use in a web page.

What Markdown flavors are supported?

Standard CommonMark Markdown plus GitHub Flavored Markdown (GFM) extensions: tables, strikethrough, and task lists.
