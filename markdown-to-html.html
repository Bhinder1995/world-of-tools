Frequently Asked Questions

What is Markdown?

Markdown is a lightweight markup language using plain text formatting. # for headers, ** for bold, etc.

Markdown for bold text?

Wrap with **double asterisks**: **bold** becomes bold.

Markdown for headers?

Use # for H1, ## for H2, ### for H3.

Does it support tables?

Yes. Use pipes and dashes to create tables: | Col1 | Col2 |

Is my text uploaded?

No. Conversion runs entirely in your browser.
